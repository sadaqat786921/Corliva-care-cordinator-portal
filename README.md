# CORLIVA — Care Coordinator Portal

Clickable prototype of the Care Coordinator web portal for the CORLIVA home care platform. Same design system as the Agency Admin portal.

**Pages:** Sign in · My work · Referrals (+ full referral screen) · Clients (+ full client screen: Overview, Contacts, Care plan, Documents, Visits) · Family requests · Schedule · Cover needed · Today’s visits · Caregivers · Incidents · Settings

```
npm install
npm run dev
```

Demo sign-in: any email and password, then security code 246810. See `AGENTS.md` for the design rules and every flow.
